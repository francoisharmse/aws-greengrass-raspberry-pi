Ultrasonic Sensor Project Overview¶

The Ultrasonic Sensor project is a comprehensive IoT solution that measures distance using an HC-SR04 ultrasonic sensor, publishes data to AWS IoT Core, and displays real-time information on an LCD screen.

Features¶

Distance Measurement¶

  • Sensor: HC-SR04 ultrasonic sensor
  • Range: 2cm to 400cm
  • Accuracy: ±3mm
  • Measurement Interval: Every 30 seconds

System Monitoring¶

  • CPU Usage: Real-time CPU utilization percentage
  • Memory Usage: RAM usage in percentage and MB
  • OS Information: Operating system version
  • GPS Coordinates: Static location data (configurable)

Data Publishing¶

  • Protocol: MQTT over TLS
  • Topic: gestel/pi4b/sensor
  • QoS: At Least Once (QoS 1)
  • Format: JSON payload with timestamp

Display¶

  • Hardware: 16x2 LCD with I2C interface
  • Information Shown:
  • Distance measurement in centimeters
  • CPU usage percentage
  • Memory usage percentage

Message Format¶

The sensor publishes JSON messages with the following structure:

{
  "time": 1699360800,
  "sensor_reading": 45.67,
  "gps": {
    "latitude": 52.0907,
    "longitude": 5.1214
  },
  "system": {
    "os_version": "Linux 6.1.21-v8+",
    "memory_usage_percent": 45.2,
    "memory_used_mb": 1804.5,
    "memory_total_mb": 3993.6,
    "cpu_usage_percent": 12.5
  }
}

Component Details¶

  • Component Name: co.is.ultrasonicsensor
  • Component Version: 1.0.3
  • Publisher: co.is.fran
  • Platform: Linux ARM64 (aarch64)

Dependencies¶

Greengrass Components¶

  • aws.greengrass.Nucleus (>=2.0.0 <3.0.0) - HARD
  • aws.greengrass.Cli (>=2.0.0 <3.0.0) - SOFT
  • aws.greengrass.SystemsManagerAgent (1.3.2) - Deployment

Python Packages¶

  • awsiotsdk - AWS IoT Device SDK
  • awscrt - AWS Common Runtime
  • RPi.GPIO - Raspberry Pi GPIO library
  • smbus - I2C communication
  • psutil - System monitoring

Use Cases¶

  1. Distance Monitoring: Track object proximity or liquid levels
  2. Parking Sensors: Detect vehicle presence
  3. Inventory Management: Monitor stock levels
  4. Security: Detect motion or intrusion
  5. IoT Learning: Educational platform for edge computing
