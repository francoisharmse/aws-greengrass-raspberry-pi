AWS IoT Greengrass Projects¶

Welcome to the AWS IoT Greengrass projects documentation for Raspberry Pi. This repository contains multiple IoT projects that demonstrate how to build edge computing solutions using AWS Greengrass V2.

Overview¶

This documentation covers three main projects:

🔊 Ultrasonic Sensor Project¶

A distance measurement system using the HC-SR04 ultrasonic sensor that: - Measures distance in real-time - Publishes sensor data to AWS IoT Core via MQTT - Displays readings on a 16x2 LCD display - Monitors system metrics (CPU, memory, OS version) - Includes GPS coordinates - Fully managed via AWS CDK infrastructure as code

🔘 Button Listener Project¶

A GPIO button press detector that: - Monitors button state changes - Publishes events to AWS IoT Core - Displays status on LCD screen - Demonstrates edge event processing

📺 LCD Display Library¶

A reusable I2C LCD controller library that: - Supports 16x2 character displays - Uses PCF8574 I/O expander - Provides simple API for text display - Used across multiple projects

Architecture¶

All projects are built on:

  • Hardware: Raspberry Pi 4 (ARM64)
  • Edge Runtime: AWS Greengrass V2
  • Infrastructure: AWS CDK (Python)
  • Communication: MQTT over AWS IoT Core
  • Monitoring: CloudWatch Logs
  • Remote Management: AWS Systems Manager

Key Features¶

✅ Infrastructure as Code: Complete AWS CDK stacks for reproducible deployments ✅ Edge Computing: Local processing with cloud connectivity ✅ Real-time Data: MQTT publishing for sensor readings ✅ System Monitoring: Built-in CPU, memory, and system metrics ✅ Remote Management: AWS Systems Manager integration ✅ Secure: IAM roles, policies, and certificate-based authentication

Quick Start¶

  1. Prerequisites: Set up your Raspberry Pi and AWS account
  2. Install Greengrass: Deploy the Greengrass V2 core software
  3. Deploy Infrastructure: Use AWS CDK to provision resources
  4. Deploy Components: Push components to your device
  5. Monitor: View logs and data in AWS Console
